# Holberton Shell

Premiers projets sur le shell Linux à Holberton School. Chaque dossier couvre un thème et contient des scripts shell courts, un par tâche.

## Projets

| Dossier | Contenu |
|---|---|
| `basics` | Navigation, manipulation de fichiers et de dossiers, liens et chemins |
| `init_files_variables_and_expansions` | Fichiers d'initialisation, variables, alias et expansions du shell |
| `io_redirections_and_filters` | Redirections d'entrée et de sortie, filtres de texte (cut, sort, uniq) |
| `permissions` | Droits d'accès aux fichiers, propriétaires et changement de permissions |

## Prérequis

- Ubuntu 20.04 LTS
- Interpréteur sh

## Utilisation

```bash
cd basics
./nom_du_script
```
